# HospIT — Տեխնիկական նշումներ (ծրագրավորողի համար)

> **DevOps-ի համար ամբողջական ուղեցույցը՝ `web/README.md` (անգլերեն)։** Այնտեղ են Docker-ով և Node-ով տեղադրումը, env փոփոխականները, reverse proxy-ն, հին Supabase-ից տվյալների տեղափոխումը, backup-ը և ստուգման հրամանները։

## Ենթակառուցվածք (2026-10-27-ից)
- **Կոդ:** `web/` — Next.js 15 (App Router) + TypeScript։ Frontend-ը և backend-ը մեկ հավելված են։
- **Բազա:** սովորական **PostgreSQL 13+** (`pg` փաթեթ)։ Supabase-ը այլևս ՉԻ օգտագործվում։
- Բազայում է ամեն ինչ՝ բովանդակությունը, օգտատերերը, մուտքի նստաշրջանները և ադմինկայից վերբեռնված նկարները (`media` աղյուսակ)։
- **Մաքուր ստատիկ hosting-ը բավարար չէ.** ադմինկան, մուտքը, կապի ձևը և վիկտորինան աշխատում են սերվերում։ Պետք է Node.js 20.9+ (կամ Docker) + PostgreSQL։
- Env փոփոխականներ՝ 1 պարտադիր (`DATABASE_URL`), մնացածը ոչ պարտադիր (`DATABASE_SSL`, `SITE_URL`, `RESEND_API_KEY`, `MAIL_FROM`, `CONTACT_TO_EMAIL`, `COOKIE_SECURE`)։ Ձևանմուշ՝ `web/.env.local.example`։ Իրական արժեքները փաթեթում ՉԿԱՆ։
- Բոլոր փոփոխականները կարդացվում են **աշխատանքի ժամանակ** (ոչ թե build-ի)։ Բովանդակությունը նույնպես կարդացվում է բազայից ամեն հարցման ժամանակ՝ ադմինկայի փոփոխությունը կայքում երևում է անմիջապես, առանց նոր build-ի։

## Տեղադրում
```
cd web
npm install
npm run db:setup                                  # աղյուսակներ + սկզբնական բովանդակություն (անվտանգ է կրկնել)
npm run db:create-admin -- admin@hospit.am 'Գաղտնաբառ123' "Անուն Ազգանուն"
npm run dev                                       # http://localhost:3000
npx tsc --noEmit                                  # տիպերի ստուգում
npx next build                                    # ՄԻ գործարկեք, երբ `npm run dev`-ը աշխատում է (նույն .next թղթապանակը)
docker compose up -d --build                      # սեփական սերվերում՝ կայք + PostgreSQL (կարդում է web/.env)
```

## Կառուցվածք
- **Հանրային կայք**՝ `src/components/site/Home.tsx` (SPA), ոճերը՝ `site.css` (`.hp-root`-ի տակ)։
- **Գնային հաշվիչ**՝ `src/components/site/PricingCalc.tsx`։ Բանաձևը՝ `src/lib/pricing.ts`։
- **Բովանդակություն**՝ `src/lib/defaults.ts` (սկզբնական տեքստեր) + `src/lib/content.ts loadContent()` (բազայից մեկ հարցմամբ, deep-merge, բազայի բացակայության դեպքում՝ սկզբնականը)։
- **Նոր տվյալները առանց նոր աղյուսակի** պահվում են `app_settings.data`-ում՝ pricing, faqs, integrations, comparison, privacy, կայքի նկարները, quiz։
- **Ադմինկա**՝ `src/app/admin/*`, բաղադրիչները՝ `src/components/admin/*`։ Server actions՝ `admin/actions.ts` (բովանդակություն, նկարներ), `admin/users-actions.ts` (օգտատերեր), `admin/quiz-actions.ts`։
- **Նկարներ**՝ վերբեռնվում են `media` աղյուսակ, բացվում են `/media/<id>.<ext>` հասցեով (`src/app/media/[file]/route.ts`)։ Թույլատրված՝ PNG, JPG, WEBP, GIF, SVG, AVIF, ICO, մինչև 7MB։
- **Վիկտորինա**՝ `/quiz`, `/quiz/board`, `/admin/quiz`, API՝ `src/app/api/quiz/route.ts`։ Մանրամասն՝ `04-ՎԻԿՏՈՐԻՆԱ.md`։
- **Մուտք / գրանցում / անձնական էջ**՝ `src/app/login`, `register`, `account`, `reset-password`, `src/app/auth/actions.ts`, `src/components/account/*`։

## 🔒 Մուտք և իրավասություններ (ԿԱՐԵՎՈՐ)
- Սեփական համակարգ է, արտաքին ծառայություն չկա (`src/lib/auth.ts`, `src/lib/password.ts`)։
- Գաղտնաբառերը պահվում են միայն հեշով (scrypt)։ Մուտքից հետո բրաուզերը ստանում է պատահական token `httpOnly` cookie-ում (`hospit_session`, 30 օր), բազայում պահվում է միայն դրա հեշը (`sessions` աղյուսակ)։
- Իրավասության **միակ աղբյուրը** `users.role`-ն է (`admin` | `client`)։ Ստուգվում է սերվերում ամեն հարցման ժամանակ, ուստի ադմինկայում փոփոխությունը գործում է անմիջապես։
- Գրանցումը (`app/account/actions.ts`) միշտ ստեղծում է `client`։ Պաշտպանություններ՝ honeypot դաշտ, լրացման նվազագույն ժամանակ։
- Մուտքի սխալ փորձերի սահմանափակում՝ 10 սխալ 15 րոպեում մեկ էլ. փոստի համար։
- Չի կարելի ջնջել/իջեցնել վերջին ադմինին, ինքն իրեն ջնջել կամ ինքն իրենից հանել ադմինի իրավունքը։
- Ադմինը օգտատիրոջ համար նոր գաղտնաբառ սահմանելիս՝ այդ օգտատիրոջ բոլոր բաց նստաշրջանները փակվում են։
- **Գաղտնաբառի վերականգնում էլ. փոստով** աշխատում է միայն, եթե տրված են `RESEND_API_KEY` և `SITE_URL`։ Հակառակ դեպքում «Մոռացե՞լ եք գաղտնաբառը»-ն ասում է դիմել ադմինին, և ադմինը նոր գաղտնաբառ է սահմանում «Օգտատերեր» բաժնից։

## Բազա
- Աղյուսակներ՝ `web/db/schema.sql`։ Սկզբնական բովանդակություն՝ `web/db/seed.sql` (գեներացվում է `npm run db:gen-seed`-ով `defaults.ts`-ից)։
- `npm run db:setup`-ը կարելի է գործարկել քանի անգամ ուզեք. ստեղծում է պակասողը և **երբեք չի վերագրում** ադմինկայում արված փոփոխությունները։ Docker-ը այն գործարկում է ինքնաշխատ ամեն մեկնարկի ժամանակ։
- **Հին Supabase-ից տեղափոխում**՝ `npm run db:import-supabase` (տես `web/README.md` §5)։ Տեղափոխում է բովանդակությունը, նկարները, հարցումները, վիկտորինան և օգտատերերին **իրենց նույն գաղտնաբառերով**։ Դրա համար Supabase նախագիծը պետք է ակտիվ լինի (եթե «paused» է՝ Restore)։
- **Backup**՝ `pg_dump` (տես `web/README.md` §6)։ Մեկ բազա = ամբողջ կայքը։
- **Բազայի խափանման դեպքում** հանրային էջը 5 վայրկյանից ավելի չի սպասում և ցույց է տալիս սկզբնական բովանդակությունը։ Ադմինկան այդ դեպքում ցույց է տալիս սխալ, որպեսզի սկզբնական տեքստերը պատահաբար չպահպանվեն իրականի փոխարեն։

## Ընտրովի բարելավումներ
- **Նամակներ.** Resend-ում հաստատել `hospit.am` դոմեյնը և տալ `RESEND_API_KEY`, `MAIL_FROM`, `SITE_URL`։
- **hospit.am դոմեյն.** DNS-ը ուղղել նոր սերվերին (տես `web/README.md` §4)։
- **SEO.** Յուրաքանչյուր բաժնին առանձին URL, `sitemap.xml`, `robots.txt`, hreflang, JSON-LD։ Մասնավոր էջերը (`/login`, `/register`, `/account`, `/admin`) արդեն `noindex` են։
