# 05 — Դոմեն կապել ձեր սերվերին (ավտոմատ)

Այս ուղեցույցը՝ ինչպես կայքը դնել **ձեր սեփական սերվերի** վրա և կապել **ձեր դոմենին**՝ գրեթե ամբողջովին ավտոմատ (մեկ script-ով)։

---

## Ի՞նչ է պետք նախապես (3 բան)

1. **Linux սերվեր** (VPS)՝ **Ubuntu 20.04 / 22.04 / 24.04**, հանրային **IP հասցեով**, root/sudo մուտքով (SSH)։ Բացված պորտեր՝ **80** և **443**։
2. **Ձեր դոմենը** + մուտք դրա **DNS կարգավորումներին** (registrar-ի / hosting-ի վահանակ)։
3. Այս փաթեթի **`web/`** թղթապանակը (zip-ից)։

---

## Քայլ 1 — Ուղղեք դոմենը սերվերին (DNS)

Ձեր դոմենի DNS կարգավորումներում ավելացրեք **2 A-գրառում**՝ ձեր սերվերի IP-ով.

| Type | Name/Host | Value (Ձեր սերվերի IP) | TTL |
|------|-----------|------------------------|-----|
| A | `@` | `ՁԵՐ.ՍԵՐՎԵՐԻ.IP` | 300 |
| A | `www` | `ՁԵՐ.ՍԵՐՎԵՐԻ.IP` | 300 |

> Սպասեք 5–30 րոպե, մինչև DNS-ը թարմանա։ Ստուգել կարող եք՝ `ping ՁԵՐԴՈՄԵՆԸ` (պետք է ցույց տա ձեր IP-ն)։

---

## Քայլ 2 — Վերբեռնեք կոդը սերվեր

Ձեր համակարգչից (կամ devops-ը), `web/` թղթապանակը դրեք սերվերի `/var/www/luystech`-ում.

```bash
# համակարգչից (scp օրինակ)
scp -r web/  root@ՁԵՐ.ՍԵՐՎԵՐԻ.IP:/var/www/luystech
```

> Կամ վերբեռնեք zip-ը սերվեր ու բացեք՝ `unzip luystech.zip && mv luystech/web /var/www/luystech`

---

## Քայլ 3 — Գործարկեք ավտոմատ script-ը

SSH-ով մտեք սերվեր և գործարկեք (փոխարինեք ձեր դոմենով ու էլ.փոստով).

```bash
cd /var/www/luystech
sudo bash deploy.sh luystech.am admin@luystech.am
```

Script-ը ինքն է անում **ամեն ինչ**.
1. Տեղադրում է Node.js 20, nginx, PM2, certbot
2. `npm ci` + `npm run build`
3. Գործարկում է կայքը PM2-ով (ֆոնային, ավտո-վերագործարկվող)
4. Կարգավորում է nginx reverse proxy
5. Ստանում է անվճar **SSL վկայական** (https) Let's Encrypt-ից

Ավարտին կգրի՝ `✅ ՊԱՏՐԱՍՏ Է՝ https://ՁԵՐԴՈՄԵՆԸ`

> ⚠️ Եթե Windows-ից եք վերբեռնել ու script-ը սխալ տա (`bad interpreter`), նախ գործարկեք՝
> `sed -i 's/\r$//' deploy.sh` ապա նորից՝ `sudo bash deploy.sh ...`

---

## Քայլ 4 — Supabase-ի կարգավորում (1 րոպե)

Որ ադմինի «գաղտնաբառ մոռացա» email-երը ճիշտ աշխատեն նոր դոմենով.
1. Supabase Dashboard → **Authentication → URL Configuration**
2. **Site URL**՝ `https://ՁԵՐԴՈՄԵՆԸ`
3. **Redirect URLs**՝ ավելացրեք `https://ՁԵՐԴՈՄԵՆԸ/**`

> Սովորական մուտքին (login) սա պետք չէ — միայն password-reset email-երի համար։

---

## Պատրա՛ստ է

- Կայք՝ **https://ՁԵՐԴՈՄԵՆԸ**
- Ադմին՝ **https://ՁԵՐԴՈՄԵՆԸ/login**

## Հետագա թարմացումներ (կոդ փոխելիս)

```bash
cd /var/www/luystech
git pull   # կամ նոր ֆայլերը վերբեռնեք
npm ci
npm run build
pm2 restart luystech
```

## Օգտակար հրամաններ

| Հրաման | Ինչ է անում |
|--------|-------------|
| `pm2 status` | Կայքի վիճակը |
| `pm2 logs luystech` | Լոգերը (սխալ փնտրելու համար) |
| `pm2 restart luystech` | Վերագործարկել |
| `sudo systemctl reload nginx` | nginx-ը վերաբեռնել |
| `sudo certbot renew` | SSL երկարաձգել (ավտոմատ էլ է լինում) |
