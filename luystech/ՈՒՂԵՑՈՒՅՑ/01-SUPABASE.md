# 01 — Supabase (տվյալների բազա)

Supabase-ը այն «պահեստն» է, որտեղ պահվում են Ձեր կայքի բոլոր տեքստերն ու տվյալները։

## Քայլ 1 — Ստեղծել հաշիվ և նախագիծ

1. Բացեք **https://supabase.com** → **Start your project** → մուտք գործեք (կարող եք GitHub-ով կամ էլ. փոստով)։
2. Սեղմեք **New project**.
   - **Name**: `luystech`
   - **Database Password**: ստեղծեք ուժեղ գաղտնաբառ և **պահեք այն** մի տեղ (կպետք գա հազվադեպ)։
   - **Region**: ընտրեք **Europe (eu-central / Frankfurt)** (Հայաստանին ամենամոտն է)։
3. Սեղմեք **Create new project** և սպասեք ~2 րոպե, մինչև պատրաստ լինի։

## Քայլ 2 — Ստեղծել աղյուսակները (schema)

1. Ձախ մենյուից → **SQL Editor** → **New query**.
2. Բացեք `web/supabase/schema.sql` ֆայլը, պատճենեք **ամբողջ** պարունակությունը։
3. Փակցրեք SQL Editor-ում → սեղմեք **Run** (կամ Ctrl+Enter)։
4. Պետք է գրի **Success**։

## Քայլ 3 — Լցնել սկզբնական տվյալները (seed)

1. Նույն **SQL Editor**-ում → **New query**.
2. Բացեք `web/supabase/seed.sql`, պատճենեք ամբողջը, փակցրեք, սեղմեք **Run**։
3. Սա լցնում է կայքի բոլոր տեքստերն ու քարտերը՝ որ ադմինում ունենաք խմբագրելու բան։

## Քայլ 4 — Վերցնել բանալիները (keys)

1. Ձախ մենյու → **Project Settings** (ատամնանիվ) → **API**.
2. Պատճենեք և պահեք այս 3 արժեքները.
   - **Project URL** — օր. `https://abcxyz.supabase.co`
   - **anon public** բանալի (երկար տեքստ)
   - **service_role** բանալի (երկար տեքստ — **գաղտնի պահեք**)

Դրանք կպետք գան Vercel-ում (տես `02-VERCEL.md`)։

## Քայլ 5 — Ստեղծել ադմին օգտատեր

1. Ձախ մենյու → **Authentication** → **Users** → **Add user** → **Create new user**.
   - **Email**: Ձեր էլ. փոստը (օր. `admin@luystech.am` կամ Ձեր անձնականը)
   - **Password**: ստեղծեք գաղտնաբառ (սա կլինի ադմին մուտքի գաղտնաբառը)
   - ✅ նշեք **Auto Confirm User**
   - **Create user**
2. Հիմա այդ օգտատիրոջը դարձնենք ադմին. **SQL Editor** → **New query** → գործարկեք (փոխարինեք Ձեր էլ. փոստով).

```sql
update public.profiles
set role = 'admin'
where email = 'ՁԵՐ_ԷԼ_ՓՈՍՏԸ_ԱՅՍՏԵՂ';
```

> Եթե տողը չգտնվի (0 rows), նշանակում է պրոֆիլը դեռ չի ստեղծվել — վերագործարկեք վերևի հրամանը մի քանի վայրկյան հետո, կամ դուրս/ներս եկեք Users-ից։

Պատրա՛ստ է։ Այժմ անցեք **`02-VERCEL.md`**-ին։
