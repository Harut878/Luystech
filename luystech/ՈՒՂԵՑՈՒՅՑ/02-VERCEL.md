# 02 — Vercel (կայքը ինտերնետում)

Vercel-ը այն վայրն է, որտեղ Ձեր կայքն «ապրում է» և հասանելի է բոլորին։

## Քայլ 1 — Ստեղծել հաշիվ

1. Բացեք **https://vercel.com** → **Sign Up**.
2. Ամենահեշտն է մուտք գործել **GitHub**-ով (եթե GitHub չունեք, ստեղծեք՝ github.com)։

## Քայլ 2 — Վերբեռնել կոդը

Երկու տարբերակ.

### Ա) Ես անեմ Ձեր փոխարեն (առաջարկվող)
Ուղարկեք ինձ.
- Supabase **Project URL**, **anon** և **service_role** բանալիները (01 ուղեցույցի Քայլ 4-ից)
- Vercel մուտքի թույլտվություն (token) — կամ պարզապես ասեք, ու ես կուղղորդեմ, թե ինչպես ստեղծել այն

Ես կվերբեռնեմ, կմիացնեմ ու կստուգեմ, որ ամեն ինչ աշխատի։

### Բ) Ինքներդ (GitHub-ով)
1. Կոդը դրեք GitHub repository-ում (ես կարող եմ օգնել)։
2. Vercel → **Add New → Project** → ընտրեք repository-ն։
3. **Root Directory**: սեղմեք **Edit** → ընտրեք **`web`**։
4. **Environment Variables** բաժնում ավելացրեք (01-ի Քայլ 4-ի արժեքներով).

| Name | Value |
|------|-------|
| `NEXT_PUBLIC_SUPABASE_URL` | Ձեր Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon բանալի |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role բանալի |
| `NEXT_PUBLIC_SITE_URL` | Ձեր Vercel հասցեն (օր. `https://luystech.vercel.app`) |

5. Սեղմեք **Deploy** և սպասեք ~2 րոպե։

## Քայլ 3 — Ստուգել

- Բացեք Ձեր Vercel հասցեն (օր. `https://luystech.vercel.app`) — կայքը պետք է բացվի։
- Բացեք `.../login` → մուտք գործեք ադմին էլ.փոստով ու գաղտնաբառով (01-ի Քայլ 5)։
- Պետք է բացվի ադմին վահանակը։

## Քայլ 4 — (Հետո) Դոմեն միացնել

Երբ գնեք դոմեն (օր. `luystech.am`).
1. Vercel → Ձեր նախագիծ → **Settings → Domains** → ավելացրեք դոմենը։
2. Vercel-ը ցույց կտա DNS գրառումներ (A / CNAME) — դրանք ավելացրեք դոմենի մատակարարի մոտ։
3. `NEXT_PUBLIC_SITE_URL`-ը փոխեք նոր դոմենով և վերբեռնեք նորից։

> Այս պահին դոմեն դեռ չկա — կայքն աշխատում է Vercel-ի անվճար հասցեով, ինչը լիովին բավարար է սկսելու համար։
