# LuysTech — Ընդհանուր ուղեցույց

Բարև Ձեզ։ Սա Ձեր նոր կայքն է՝ **LuysTech** (Business Control արտադրանքով)։

> ✅ **Կայքը ԱՐԴԵՆ ՈՆԼԱՅՆ Է՝** **https://luystech.vercel.app**
> Ադմին մուտք՝ **https://luystech.vercel.app/login** · էլ.փոստ `claude@itx.am` · գաղտնաբառ `LuysTech2026!` (փոխեք)

## Ի՞նչ է սարքվել

- **Հանրային կայք** (գլխավոր էջ)՝ 3 լեզվով (Հայերեն / English / Русский), մուգ ու բաց թեմաներով, հարուստ անիմացիաներով, հարմարեցված բոլոր սարքերին (հեռախոս, պլանշետ, համակարգիչ)։
- **Ադմին վահանակ** (`/admin` հասցեով)՝ ամբողջովին հայերեն, որտեղ Դուք կարող եք փոխել կայքի **բոլոր** արժեքները՝ առանց ծրագրավորողի.
  - Բոլոր տեքստերը (3 լեզվով)
  - Business Control մոդուլները (Վաճառք, Պահեստ և այլն)
  - Առավելությունները, վիճակագրությունը, ոլորտները
  - Հաճախորդներին, գործընկերներին, հաջողության պատմությունները
  - Կոնտակտային տվյալները, սոցիալական ցանցերը
  - Կապի ձևից եկած հարցումները (տեսնել/կառավարել)

## Բաղադրիչները

| Ի՞նչ | Ինչի՞ համար |
|------|-------------|
| **Next.js** (կոդը `web/` թղթապանակում) | Հենց կայքը |
| **Supabase** | Տվյալների բազա (որտեղ պահվում են Ձեր փոփոխությունները) |
| **Vercel** | Հոսթինգ (որտեղ կայքն ապրում է ինտերնետում) |

## Հաջորդ քայլերը (ըստ հերթականության)

1. **`01-SUPABASE.md`** — ստեղծել Supabase հաշիվ ու տվյալների բազա։
2. **`02-VERCEL.md`** — կայքը վերբեռնել ինտերնետ (Vercel)։
3. **`03-ԱԴՄԻՆ-ՁԵՌՆԱՐԿ.md`** — ինչպես ամեն օր փոխել կայքի բովանդակությունը։

> 💡 Դուք ընտրել եք **նոր, առանձին հաշիվներ** Supabase-ի և Vercel-ի համար։ 01 և 02 ուղեցույցները ցույց են տալիս՝ ինչպես ստեղծել դրանք։ Երբ ստեղծեք, կարող եք բանալիներն ուղարկել ինձ՝ որ ես ավարտեմ միացումն ու վերբեռնումը, կամ անել ինքներդ՝ քայլերով։

## Լոկալ գործարկում (Ձեր համակարգչում, փորձարկելու համար)

Պարտադիր չէ, բայց եթե ուզում եք տեսնել կայքը Ձեր համակարգչում.

```bash
cd web
npm run dev
```

Ապա բացեք բրաուզերում՝ **http://localhost:3000**

> Առանց Supabase-ի կայքը դեռ կաշխատի՝ ցուցադրելով կանխադրված (ներկառուցված) տվյալները։ Ադմինը կաշխատի միայն Supabase-ը միացնելուց հետո։
