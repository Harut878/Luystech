# 03 — Ադմին ձեռնարկ (ամենօրյա օգտագործում)

Այստեղ բացատրվում է՝ ինչպես ինքներդ փոխել կայքի ցանկացած արժեք։

## Մուտք գործել

1. Բացեք Ձեր կայքի հասցեն + `/login` (օր. `https://luystech.vercel.app/login`)։
2. Մուտքագրեք ադմին էլ. փոստն ու գաղտնաբառը։
3. Կբացվի **ադմին վահանակը**։ Ձախ կողմում մենյուն է։

## Ձախ մենյուի բաժինները

| Բաժին | Ի՞նչ եք խմբագրում |
|-------|------------------|
| **Վահանակ** | Ընդհանուր պատկեր + վերջին հարցումները |
| **Տեքստեր** | Կայքի **բոլոր** գրվածքները՝ 3 լեզվով (վերնագրեր, կոճակներ, մենյու և այլն) |
| **Մոդուլներ (BC)** | Business Control-ի քարտերը (Վաճառք, Պահեստ…) |
| **Առավելություններ** | «Ինչու BC» քարտերը |
| **Վիճակագրություն** | Մեծ թվերը (60%, 40%, 99.9%) |
| **Ոլորտներ** | Ոլորտների քարտերը |
| **Հաճախորդներ** | Հաճախորդների լոգոները |
| **Գործընկերներ** | Գործընկերների քարտերը |
| **Պատմություններ** | Հաջողության պատմությունները |
| **Թվեր (Proof)** | «120+», «50K+» ցուցանիշները |
| **Կապ և կարգավորումներ** | Հեռախոս, էլ.փոստ, հասցե, սոց. ցանցեր, թեմա, լեզու |
| **Հարցումներ** | Կապի ձևից եկած նամակները |

## Ինչպես փոխել տեքստ

1. Բացեք **Տեքստեր**։
2. Սեղմեք բաժնի անվան վրա (օր. «Գլխավոր էկրան»)՝ բացելու համար։
3. Ամեն դաշտի վրա կան 3 լեզվի կոճակներ՝ **Հայ / EN / РУ**։ Ընտրեք լեզուն և փոխեք տեքstը։
4. Վերջում սեղմեք **Պահպանել բոլորը**։ Փոփոխությունը միանգամից երևում է կայքում։

## Ինչպես ավելացնել/փոխել քարտ (մոդուլ, ոլորտ, հաճախորդ…)

1. Բացեք համապատասխան բաժինը (օր. **Ոլորտներ**)։
2. **Ավելացնելու** համար՝ սեղմեք **+ Ավելացնել**, լրացրեք դաշտերը, **Պահպանել**։
3. **Փոխելու** համար՝ սեղմեք քարտի **Խմբագրել**, փոխեք, **Պահպանել**։
4. **Ջնջելու** համար՝ **Ջնջել**։
5. **Ակտիվ** անջատիչը որոշում է՝ քարտը երևա՞ կայքում, թե՞ ոչ (առանց ջնջելու)։
6. **Հերթականություն** թիվը որոշում է շարքը (փոքր թիվն առջևում է)։

## Ինչպես վերբեռնել նկար/լոգո

- Նկարի դաշտում սեղմեք **Վերբեռնել նկար** → ընտրեք ֆայլը համակարգչից։ Ինքնաբերաբար կպահվի ու կերևա։
- Հեռացնելու համար՝ **Հեռացնել**։

## Կոնտակտային տվյալներ և կարգավորումներ

Բացեք **Կապ և կարգավորումներ**.
- Հեռախոս, էլ. փոստ, հասցե, աշխատանքային ժամեր
- Սոցիալական ցանցերի հղումներ (LinkedIn, Facebook, X)
- Google Maps քարտեզ (ոչ պարտադիր)
- Կանխադրված լեզու և թեմա (մուգ/բաց)
- Դեղին/երկնագույն շեշտ, «Պատմություններ» բաժնի ցուցադրում

## Հարցումներ

**Հարցումներ** բաժնում երևում են կայքի կապի ձևից եկած բոլոր նամակները՝ ընկերություն, անձ, հեռախոս, էլ.փոստ, հաղորդագրություն։ Կարող եք նշել կարգավիճակը (Նոր → Կապ հաստատված → Ավարտված) կամ ջնջել։

## Կարևոր խորհուրդներ

- Ամեն փոփոխությունից հետո անպայման սեղմեք **Պահպանել**։
- Փոփոխությունները երևում են կայքում մի քանի վայրկյանում (թարմացրեք էջը)։
- Եթե ինչ-որ բան սխալ գնա, միշտ կարող եք նորից գործարկել `seed.sql`-ը՝ սկզբնական տեքստերը վերականգնելու համար (բայց դա կվերագրի Ձեր փոփոխած տեքստերը)։
